# SEO 與首頁素材驗證

日期：2026-11-12。正確專案：獨立 `stair-kids` repository。

- 更新繁中、簡中及英文 SEO 標題與描述，OG／Twitter／JSON-LD 改用獨立 `seo.webp`。
- 有標題 SEO 圖與無文字 cover 各自生成、轉為 1200 × 675 WebP；原圖與完整提示詞保存在 `assets/marketing/`。
- 首頁沿用遊戲角色與 SVG 階梯，桌機左右排列，手機／平板直向上下排列；修正窄版英文、平板與手機橫向版面。
- 保留獨立專案原有的大廳聊天室腳本、樣式與設定。
- `npm test` 通過，涵蓋 SEO 注入、三語系、遊戲規則與視覺元件。
- `npm run verify` 通過，涵蓋 AI、多人、結算、聊天、完整流程與平滑度。
- 在本專案伺服器 `localhost:3061` 驗證三語系 × 六尺寸（320 × 740、390 × 844、768 × 1024、1024 × 768、1440 × 900、844 × 390），18 組首頁皆無水平／垂直溢出、插畫重疊、超出視窗的主要按鈕或瀏覽器程式錯誤。
- 瀏覽器確認 SEO metadata、新增分享圖及 cover 均可載入，兩張圖片實際解碼尺寸為 1200 × 675。
- 沿用既有格式手動整理修改區域，`git diff --check` 通過。
- 截圖、尺寸測量與測試輸出保存在 Git 忽略的 `screenshots/`，不含於正式素材。

依 loop-engineering 的有界檢查流程，以測試及實際瀏覽器尺寸檢查作為完成依據。未在真實觸控硬體逐一測試所有遊戲狀態；此次移轉未改動遊戲規則、連線邏輯或測試。
