# 小朋友下樓梯（stair-kids）

只有左右移動、沒有跳躍鍵的下樓梯遊戲。往下踩住樓梯、避開刺階與追來的天花板；深度越深，分數越高。
目前支援單人挑戰、本機電腦對戰、線上雙人對戰、觀戰、邀請與聊天。介面支援繁體中文、簡體中文與英文。

## 啟動

使用 Node.js 執行 `npm start`，或雙擊 `啟動遊戲.bat`，開啟 <http://localhost:3060>。
後端零外部相依套件；埠號可用環境變數 `PORT` 調整。
直接以瀏覽器開啟 `public/index.html` 也能遊玩單機模式，線上功能需要連到遊戲伺服器。

## 模式、操作與勝負

- 單人挑戰有幼幼班、簡單、普通、困難四種遊戲難度。幼幼班不會死亡，按「結束這局」收局；其他難度血歸零或整個角色掉出畫面下緣即淘汰。
- 電腦對戰固定一位真人與一位電腦，共用樓梯。電腦強度可跟隨所選遊戲難度，或另外選「神話」；神話不改變共用的遊戲難度。玩家淘汰即結算，比雙方最深深度，同深度比存活時間。
- 線上固定兩位玩家，最多 20 位觀戰者。兩人都淘汰才結算；正常完賽先比最深深度，再比存活時間。結算前離開或斷線直接判輸，即使已淘汰或深度領先也一樣；雙方都棄權判平手。
- 用方向鍵或 A／D 左右移動；觸控裝置使用左右按鍵。Esc 開啟選單，單機可暫停，線上不暫停。
- 側面碰撞會互相推擠；從上方落到對手頭頂可以站住。踩頭不扣血、不回血、不計推擠；下面的人下落或彈起會帶動上面的人，任一方走開、支撐者淘汰或上面的人撞天花板後解除支撐。
- 兩人都按準備後，房主才能開始。對局中的空位不補入本局，新加入者先觀戰；結算回房間後才能搶位。對局中不能踢出上場玩家，房主仍可管理觀戰者。
- 結算顯示後才能確認返回房間。線上結算最多停留 10 秒，回房間後重新準備才能開下一局；每局使用新的樓梯種子。

## 樓梯、血量與場地

普通階可站立；輸送帶帶動速度為 ±3 格／秒；彈簧給向上初速 9 格／秒；假階踩到 0.25 秒後崩解。
踩到非刺的階梯回 1 顆愛心，持續站著與踩頭不會回血。刺階及天花板傷害依難度與深度決定，
刺階有 0.6 秒同類傷害無敵，天花板使用獨立冷卻。被天花板頂到會獲得向下推力。

場地寬 16 格，角色寬 1.25 格、高 2 格，水平速度 6 格／秒。
可見高度每局固定在 16～24 格，線上全房共用；轉向不改變當局死亡線。
每 100 公尺切換世界，六種世界循環使用，紀錄與設定保存在這台裝置。

## 測試

`npm test` 驗證規則核心、分析事件與三語系；`npm run verify` 執行完整規則、樓梯、AI、房間、同步、音訊及流程驗證。
`npm run test:versus` 專測棄權判輸、對局角色／權限與頭頂 AI。其他細分指令以 `package.json` 的 scripts 為準。

需要真實瀏覽器的線上驗證為 `npm run test:e2e`，須另備 Playwright 與 Chromium，先啟動本機伺服器。
可使用 `node scripts/e2e-online.js --url=http://localhost:3060`；要輸出截圖時才指定 `--shots`。
截圖、記錄檔與快取是可重建產物，驗證後清除，不提交版本控制；正式圖片、圖示、音訊、字型、規則測試及鎖定檔須保留。

## 線上房間生命週期

主動離開的空房立即關閉；等待房間若因切換 App 而全員斷線，保留 60 秒讓使用者重新連線。
此等待寬限與「對局中斷線立即判輸」是不同流程。房間關閉後邀請失效。
邀請先到大廳確認暱稱再加入，滿席或對局中先觀戰；離開線上模式會停止連線。

## 部署與架構

前端以 GitHub Pages 發布 `public/`，後端依 `render.yaml` 啟動。
`public/js/config.js` 是唯一前端 server URL 入口；`GAME_SERVER_URL` 可由 workflow 注入。
現有 Pages workflow 的優先順序是手動輸入、repository Variable、workflow 預設值。
後端的 `PORT` 與允許來源設定請參考 `.env.example`；`/health` 供伺服器／平台健康檢查使用。
是否已部署以 GitHub Actions 與實際服務回應為準，不能由本機設定檔推定。

- `public/js/rules.js`：單機、電腦模擬與伺服器共用的規則。
- `public/js/stairs.js`：固定種子的樓梯生成。
- `public/js/ai.js`：電腦控制；一般強度跟隨遊戲難度，神話使用額外模擬預算。
- `lib/rooms.js`、`lib/protocol.js`、`lib/match-loop.js`：房間、權限、30Hz 權威同步。
- `public/js/net.js`、`online.js`、`app.js`：預測、對帳、介面與畫面內插。
- `public/js/locales.js`：三語系字典；新增或修改教學須同步更新三種語言。

詳細規格見 [規劃書.md](規劃書.md)。歷史開發過程可由 Git 紀錄查閱。
